14. Onglet Visionneuse SBOM

L’onglet Visionneuse SBOM permet d’ouvrir et d’explorer n’importe quel fichier SBOM CycloneDX ou SPDX depuis le système de fichiers, indépendamment d’une génération en cours.

14.1. Ouverture d’un fichier

Cliquez sur 📂 Ouvrir un fichier SBOM… pour parcourir le système de fichiers. Le sélecteur propose les extensions .json, .jsonld, .cdx.json, .spdx.json.

Formats supportés :

  • CycloneDX 1.6 — components[] avec champs name, version, type, purl, licenses, description

  • SPDX 2.x — packages[] avec champs name, versionInfo, licenseConcluded, summary, externalRefs[purl]

  • SPDX 3.0 JSON-LD — éléments software:Package du graphe @graph, avec champs name, software:packageVersion, concludedLicense/declaredLicense, summary, externalIdentifier[purl]

La barre d’informations affiche le format détecté, le nom du document et le nombre total de composants chargés.

14.2. Filtre et recherche

Le champ de recherche filtre les composants en temps réel sur :

  • le nom du paquet

  • la version

  • la licence

  • le PURL

Le menu déroulant Tous les types filtre par type d’écosystème (rpm, java, pypi, npm, deb, apk…). Les deux filtres se combinent.

14.3. Tableau des composants

Le tableau affiche les colonnes Nom, Version, Type, Licence et PURL. Cliquez sur un en-tête de colonne pour trier par ordre croissant, cliquez à nouveau pour inverser l’ordre.

14.4. Panneau de détails

Cliquez sur une ligne du tableau pour afficher un panneau de détails sur la droite, récapitulant tous les champs du composant sélectionné : nom, version, type, licence, description et PURL.

14.5. Persistance

Le fichier ouvert et les filtres actifs sont mémorisés lors de la navigation entre onglets. Le fichier n’est pas rechargé automatiquement si son contenu change sur disque.

Note
 La Visionneuse SBOM est un onglet autonome — il peut être utilisé avec n’importe quel fichier SBOM, pas uniquement ceux générés par sbom_generator.

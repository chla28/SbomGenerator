24. Sous-commande scan — Analyse CVE en ligne de commande

La sous-commande scan permet d’exécuter les mêmes analyses CVE que le GUI directement depuis le terminal, avec filtrage par date intégré. Elle ne nécessite pas d’interface graphique.

sbom-generator scan --sbom <fichier.cdx.json> [options]

24.1. Options

Option Défaut Description

--sbom <chemin> (ou -s)

obligatoire

Fichier SBOM à analyser (CycloneDX, SPDX…)

--scanner <nom> (ou -S)

grype

Scanner à utiliser : grype, osv, trivy, ou all (les trois)

--cve-after <YYYY-MM-DD>

aucun

N’afficher que les CVE dont la date est postérieure à cette valeur (inclusive)

--cve-before <YYYY-MM-DD>

aucun

N’afficher que les CVE dont la date est antérieure à cette valeur (inclusive, fin de journée)

--cve-date-field <champ>

published

Champ de date utilisé : published, modified, ou latest (la plus récente des deux)

--include-undated

désactivé

Inclure les CVE dont le champ de date est absent des données du scanner

--help (ou -h)

—

Afficher l’aide de la sous-commande

24.2. Codes de retour

  • 0 — aucune CVE dans la plage demandée (ou aucune CVE trouvée du tout)

  • 1 — au moins une CVE trouvée dans la plage, ou erreur d’un scanner

24.3. Exemples

# Toutes les CVE Grype depuis le 1er janvier 2024
sbom-generator scan --sbom sbom.cdx.json --cve-after 2024-01-01

# CVE OSV-Scanner entre deux dates
sbom-generator scan --sbom sbom.cdx.json --scanner osv \
  --cve-after 2023-06-01 --cve-before 2024-01-01

# Tous les scanners, date de modification, CVE sans date incluses
sbom-generator scan --sbom sbom.cdx.json --scanner all \
  --cve-date-field modified --cve-after 2023-01-01 --include-undated

# Utiliser dans un script CI (retour 1 si CVE récentes détectées)
sbom-generator scan --sbom sbom.cdx.json \
  --cve-after "$(date -d '90 days ago' +%F)" && echo "OK" || echo "CVE récentes !"

24.4. Format de sortie

La commande affiche pour chaque scanner une table textuelle triée par sévérité décroissante :

── Grype ──────────────────────────────────────────
  3 CVE(s) trouvée(s)  Filtre : champ=published  après=2024-01-01

SÉVÉRITÉ      CVE / ID              PAQUET
------------  --------------------  ------------------------------------
Critical      CVE-2024-1234         openssl@1.1.1k
High          CVE-2024-5678         bash@5.0.17
Medium        CVE-2024-9012         zlib@1.2.11

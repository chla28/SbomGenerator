19. Onglet Fusion SBOM

L’onglet Fusion SBOM combine plusieurs fichiers SBOM en un seul document, en dédupliquant les composants communs. Il orchestre la sous-commande sbom-generator merge en arrière-plan.

  ┌─ [➕ Ajouter des fichiers…]  [📂 Fichiers générés]   3 fichier(s) sélectionné(s) ─┐
  │  📄 base.cdx.json         /chemin/vers/base.cdx.json                      [✕]  │
  │  📄 extra-1.cdx.json      /chemin/vers/extra-1.cdx.json                   [✕]  │
  │  📄 extra-2.cdx.json      /chemin/vers/extra-2.cdx.json                   [✕]  │
  └──────────────────────────────────────────────────────────────────────────────┘

  [ Fichier de sortie : merged.cdx.json ]  [ Nom du document (optionnel) ]  [🔀 Fusionner]

  ✔ Fusion réussie → merged.cdx.json

19.1. Sélection des fichiers à fusionner

Deux façons d’alimenter la liste :

  • ➕ Ajouter des fichiers… : ouvre un menu à deux entrées — .json / .jsonld (filtre le sélecteur sur ces extensions) ou Tous les fichiers (aucun filtre, pour les SBOM dont l’extension n’est pas .json, ex. .cdx, .spdx, bom, ou sans extension). Sélection multiple possible dans les deux cas. Le contenu doit rester du JSON CycloneDX ou SPDX 2.x quel que soit le nom du fichier.

  • 📂 Fichiers générés : menu listant les fichiers SBOM produits pendant la session courante (mêmes formats que l’onglet Arborescence, hors SPDX 3.0 — voir Contraintes ci-dessous).

Chaque fichier de la liste peut être retiré individuellement via le bouton ✕. Le bouton 🔀 Fusionner n’est actif qu’à partir de deux fichiers sélectionnés et d’un chemin de sortie renseigné.

19.2. Fichier de sortie et nom du document

  • Fichier de sortie : chemin du document fusionné produit (valeur par défaut : merged.cdx.json).

  • Nom du document (optionnel) : s’il est renseigné, remplace le nom du document dans le fichier fusionné ; sinon, le nom du premier fichier source est conservé.

19.3. Lancement et résultat

Le bouton 🔀 Fusionner lance sbom-generator merge avec les fichiers sélectionnés. Le déroulé de la commande (journal) s’affiche sous les champs, suivi d’une bannière de résultat :

  • ✔ Fusion réussie → <fichier> (vert) en cas de succès.

  • ✘ Échec de la fusion (code N) (rouge) en cas d’échec — consultez le journal affiché pour le détail de l’erreur.

19.4. Contraintes

Tous les fichiers sélectionnés doivent être dans le même format (celui du premier fichier de la liste) : CycloneDX ou SPDX 2.3. Le format de sortie suit celui du premier fichier. Le format SPDX 3.0 (JSON-LD) n’est pas pris en charge en entrée pour la fusion.

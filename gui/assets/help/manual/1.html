2. Prérequis & installation

2.1. Prérequis

Composant Obligatoire Rôle

sbom-generator

Oui

Génération des fichiers SBOM

syft

Non

Analyse d’images OCI (onglet Configuration — outil OCI par défaut)

skopeo / trivy / cdxgen

Non

Analyse d’images OCI — backends alternatifs (onglet Configuration — outil OCI) ; cdxgen requiert Node.js

trivy (analyse CVE)

Non

Analyse des vulnérabilités CVE (onglet Trivy)

grype

Non

Analyse des vulnérabilités CVE (onglet Grype)

osv-scanner

Non

Analyse des vulnérabilités CVE (onglet OSV-Scanner)

trivy

Non

Analyse des vulnérabilités CVE (onglet Trivy)

asciidoctor-pdf

Non

Conversion automatique en PDF du rapport AsciiDoc (SBOM, ou export de vulnérabilités depuis Grype/OSV-Scanner/Trivy)

sbomqs

Non

Score de qualité SBOM (option dans Configuration)

2.1.1. Vérifier que les outils sont disponibles

sbom-generator --version
syft version
grype version
osv-scanner --version
trivy --version
cdxgen --version
asciidoctor-pdf --version
sbomqs version

2.1.2. Installer syft (optionnel)

# Script officiel Anchore
curl -sSfL https://raw.githubusercontent.com/anchore/syft/main/install.sh \
  | sh -s -- -b /usr/local/bin

# Vérifier
syft version

2.1.3. Installer cdxgen (optionnel)

# Via npm (requiert Node.js ≥ 20)
npm install -g @cyclonedx/cdxgen

# Vérifier
cdxgen --version

2.1.4. Installer grype

# Script officiel Anchore
curl -sSfL https://raw.githubusercontent.com/anchore/grype/main/install.sh \
  | sh -s -- -b /usr/local/bin

# Vérifier
grype version

2.1.5. Installer osv-scanner (optionnel)

# Script officiel Google
curl -sSfL \
  https://raw.githubusercontent.com/google/osv-scanner/main/scripts/install.sh \
  | sh -s -- -b /usr/local/bin

# Ou via Go (si Go est installé)
go install github.com/google/osv-scanner/cmd/osv-scanner@latest

# Vérifier
osv-scanner --version
Note
 osv-scanner doit être accessible dans le PATH au lancement du GUI. Si l’outil est installé via Go dans ~/go/bin, ajoutez ce dossier au PATH de votre session graphique (~/.profile ou ~/.bash_profile).

2.1.6. Installer trivy (optionnel)

# Script officiel Aqua Security
curl -sfL https://raw.githubusercontent.com/aquasecurity/trivy/main/contrib/install.sh \
  | sh -s -- -b /usr/local/bin

# Ou via le gestionnaire de paquets (Fedora/RHEL)
sudo rpm -ivh https://github.com/aquasecurity/trivy/releases/latest/download/trivy_Linux-64bit.rpm

# Vérifier
trivy --version

2.1.7. Installer asciidoctor-pdf (optionnel)

gem install asciidoctor-pdf

2.1.8. Installer sbomqs (optionnel)

# Télécharger la dernière release depuis GitHub
# https://github.com/interlynk-io/sbomqs/releases
curl -sSfL https://raw.githubusercontent.com/interlynk-io/sbomqs/main/install.sh \
  | sh -s -- -b /usr/local/bin

# Vérifier
sbomqs version

2.2. Lancer l’interface

sbom_generator_gui

Si le binaire n’est pas dans le PATH, exécutez-le directement :

/chemin/vers/sbom_generator_gui

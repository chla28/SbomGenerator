3. Vue d’ensemble de l’interface

L’interface est divisée en deux panneaux séparés par un séparateur vertical.

┌────────────────────────────────────────────────────────────────────────────┐
│  🗒 SBOM Generator                     [❓] [🎨] [🌙] [ℹ]                 │
├───────────────────────┬────────────────────────────────────────────────────┤
│                       │                                                    │
│   Configuration       │ [Progression][Résultats][Grype][OSV][Trivy][Fusion][Licences][Visionneuse][Aperçu]│
│   ─────────────────   │ ─────────────────────────────────────────────────  │
│   ENTRÉE              │                                                    │
│   [fichier.lst  📂▾]  │   12 / 23  52%    bash-5.1.8-6.el9.x86_64         │
│   (glisser-déposer)   │   ████████████████░░░░░░░░░░░░                    │
│                       │                                                    │
│   SORTIE              │   $ sbom-generator --input …                      │
│   [sbom        📂▾]   │   Generating CycloneDX…                           │
│   [x] CycloneDX       │   Resolved bash-5.1.8                             │
│   [ ] SPDX 2.3        │   SBOM written → sbom.cdx.json  (42.3 KB)         │
│   [ ] AsciiDoc        │                      [Copier] [Enregistrer]       │
│   ...                 │ ┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄  │
│   OPTIONS             │  ✔ 23 paquets  •  1 fichier SBOM                  │
│   [Nom document ]     │                                                    │
│   Concurrence: 4      │                                                    │
│   [ ] Verbeux         │                                                    │
│   [ ] Score sbomqs    │                                                    │
│                       │                                                    │
│  [▶ Générer SBOM]     │                                                    │
│  $ sbom-generator …   │                                                    │
│                       │                                                    │
└───────────────────────┴────────────────────────────────────────────────────┘

Panneau gauche — Configuration : réglage de toutes les options avant le lancement. Largeur fixe (390 px). Les paramètres sont restaurés automatiquement à chaque démarrage. La commande CLI équivalente s’affiche sous le bouton ▶ Générer le SBOM et se met à jour en temps réel.

Panneau droit — Résultats : quatorze onglets — Progression (avec export des logs et résumé), Résultats (fichiers + score sbomqs), Tableau de bord (synthèse CVE multi-scanners), Grype, OSV-Scanner et Trivy (analyses CVE), Conformité CRA (rapport de conformité Cyber Resilience Act), Qualité SBOM (sbomqs + sbom-scorecard), Arborescence SBOM (exploration des composants du SBOM), Comparaison SBOM (diff de deux SBOM), Fusion SBOM (combine plusieurs SBOM en un seul), Licences SBOM (rapport de conformité des licences au format AsciiDoc), Visionneuse SBOM (exploration interactive d’un fichier SBOM externe) et Aperçu (prévisualisation du contenu SBOM).

Le bouton ❓ dans la barre de titre ouvre ce manuel utilisateur directement dans l’application (sommaire à gauche, chapitre sélectionné à droite) — à ne pas confondre avec les icônes ❓ plus petites présentes sur chaque champ/ section, qui affichent une infobulle courte au survol plutôt que d’ouvrir le manuel complet. Le champ de recherche en tête de sommaire filtre les chapitres par titre et par contenu au fur et à mesure de la frappe ; un extrait du passage trouvé s’affiche sous le titre du chapitre concerné.

Le bouton 🌙 / ☀ dans la barre de titre bascule entre mode sombre et mode clair. Le bouton 🎨 ouvre le sélecteur de couleur de thème. Les deux préférences sont sauvegardées.

Le bouton 文A (langue de l’interface) propose Système, Français et English. Système suit la langue du poste, avec repli sur le français si elle n’est pas prise en charge. Le choix s’applique immédiatement et est sauvegardé.

Note
 La traduction anglaise est en cours : pour l’instant, seuls les éléments communs aux onglets de scan et l’onglet Grype sont traduits. Les autres écrans, les rapports exportés, ce manuel et les messages du CLI restent en français.

13. Onglet Arborescence SBOM

L’onglet Arborescence SBOM permet d’explorer les composants d’un fichier SBOM (CycloneDX ou SPDX) sans ouvrir un éditeur JSON.

  ┌─ Fichier : [ sbom.cdx.json ▼ ]  [📂 Ouvrir…]                      ─┐
  │  CycloneDX 1.6  •  Mon Application 2.1.0  •  246 composants          │
  ├─ Grouper par : [Aucun] [Type] [Licence]                               │
  ├────────────────────────────────────────────────────────────────────────┤
  │ ▶ rpm  (132)                                                           │
  │ ▼ python  (89)                                                         │
  │    requests  2.31.0  MIT  pkg:pypi/requests@2.31.0                    │
  │    urllib3   1.26.14 MIT  pkg:pypi/urllib3@1.26.14                    │
  │    ...                                                                 │
  │ ▶ deb  (25)                                                            │
  └────────────────────────────────────────────────────────────────────────┘

13.1. Sélection du fichier SBOM

Le menu déroulant liste les fichiers SBOM générés dans la session courante. Le premier fichier .cdx.json, .spdx.json ou .spdx3.jsonld est sélectionné automatiquement.

Le bouton Ouvrir… permet de charger n’importe quel fichier du système de fichiers.

Formats supportés :

  • CycloneDX 1.6 — .cdx.json (champ components[])

  • SPDX 2.x — .spdx.json (champ packages[])

  • SPDX 3.0 JSON-LD — .spdx3.jsonld

13.2. Barre d’informations

Après le chargement, une ligne de métadonnées s’affiche :

  • Format et version du SBOM

  • Nom du document / composant principal

  • Nombre total de composants

13.3. Groupement

Le sélecteur Grouper par propose trois modes :

Aucun

Tous les composants dans une liste plate triée par nom

Type

Regroupement par type de paquet (rpm, python, deb…)

Licence

Regroupement par expression de licence SPDX

Les groupes sont repliables. Cliquez sur l’en-tête d’un groupe pour l’ouvrir ou le fermer.

13.4. Détails d’un composant

Cliquez sur un composant pour afficher ses détails (champ expansible) :

  • PURL (Package URL) — cliquable pour copier dans le presse-papiers

  • Version

  • Type

  • Licence

Note
 Les composants sans PURL dans le SBOM n’affichent pas ce champ.

13.5. Persistance de l’état

L’onglet mémorise son état (fichier sélectionné, groupement, groupes ouverts/fermés) lors de la navigation entre onglets.

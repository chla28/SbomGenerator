1. Introduction

1.1. Qu’est-ce qu’un SBOM ?

Un SBOM (Software Bill of Materials — inventaire logiciel) est un fichier structuré listant tous les composants d’un logiciel : paquets, bibliothèques, versions, licences. Il joue le rôle d’une nomenclature, au sens industriel du terme.

Les formats les plus répandus sont :

  • CycloneDX (JSON, recommandé par l’OWASP et l’ANSSI)

  • SPDX (standard ISO/IEC 5962:2021, adopté par la Linux Foundation)

1.2. Qu’est-ce que Grype ?

Grype (Anchore) est un scanner de vulnérabilités CVE open-source. Il analyse un fichier SBOM et le compare à des bases de données de vulnérabilités (NVD, GitHub Security Advisories…) pour identifier les paquets affectés et leur niveau de sévérité.

1.3. Présentation de l’outil

SBOM Generator GUI est une interface graphique de bureau Linux qui orchestre des outils en ligne de commande :

  • sbom-generator : génère des fichiers SBOM depuis une liste de paquets ou une image OCI

  • grype : analyse les SBOM générés pour détecter les vulnérabilités CVE (Anchore)

  • osv-scanner : analyse les SBOM pour détecter les vulnérabilités CVE (Google)

  • trivy : analyse les SBOM pour détecter les vulnérabilités CVE (Aqua Security)

  • sbomqs : calcule un score de qualité SBOM (optionnel)

  • asciidoctor-pdf : convertit le rapport AsciiDoc en PDF (optionnel)

L’interface permet de configurer les options, suivre l’exécution en temps réel, accéder aux fichiers produits, les prévisualiser, et lancer une analyse de vulnérabilités sans jamais ouvrir un terminal.

Pour chaque lancement, la ligne de commande équivalente est affichée dans l’interface — sous le bouton ▶ Générer le SBOM et comme première entrée du journal de progression.

Les paramètres sont automatiquement sauvegardés entre les sessions.

1. Démarrage rapide

Ce chapitre est le parcours de première utilisation : en cinq minutes, de l’ouverture de l’application à un tableau de bord de vulnérabilités. Le détail de chaque écran est dans les chapitres suivants.

  1. Vérifier les prérequis. L’application pilote des outils externes : le CLI sbom-generator (fourni avec l’application), puis, selon ce que vous voulez faire, syft/skopeo (images de conteneur), grype, osv-scanner, trivy (analyse de vulnérabilités), sbomqs (qualité), asciidoctor-pdf (rapports PDF). Les onglets concernés indiquent clairement l’outil manquant. Voir Prérequis & installation.

  2. Générer un premier SBOM. Dans le panneau de gauche, section Entrée, choisissez (ou glissez-déposez) un fichier de paquets, un lockfile (package-lock.json, pubspec.lock…) ou un dossier ; dans Sortie, donnez un nom de base et cochez au moins un format (CycloneDX pour commencer). Cliquez sur ▶ Générer le SBOM (ou Ctrl+Entrée). L’onglet Progression montre l’avancement ; l’onglet Résultats liste les fichiers produits.

  3. Analyser les vulnérabilités. Ouvrez l’onglet Grype, OSV-Scanner ou Trivy : le SBOM qui vient d’être généré est déjà sélectionné. Cliquez sur Analyser. Pour lancer les trois scanners d’un coup, utilisez l’onglet Tâches : mettez les analyses en file, elles s’exécutent une à une et peuvent être annulées ou relancées.

  4. Lire le tableau de bord. L’onglet Tableau de bord réunit les résultats : cartes par scanner, comparaison inter-scanners, remédiation (quelle mise à jour corrige le plus de risque), et — si vous avez déjà analysé la cible — la tendance depuis une session précédente.

  5. Décider. Dans la fiche d’une CVE, Déclarer via VEX… marque une CVE comme non affectée (avec justification) : elle disparaît du tableau de bord et s’exporte en OpenVEX ou CycloneDX VEX.

  6. Partager. Enregistrer la session… conserve les résultats dans un fichier ; Export AsciiDoc + PDF produit un rapport.

Tip
 Tout est aussi disponible au clavier : Ctrl+Entrée lance la génération, Échap l’arrête, Ctrl+1…9 change d’onglet, F1 ouvre ce manuel et Ctrl+/ affiche la liste des raccourcis (voir Raccourcis clavier). Dans le manuel, le champ de recherche surligne les occurrences dans le chapitre ; F3 / Maj+F3 passent à l’occurrence suivante / précédente.

7.1. Bannière de résultat

  • Fond vert : génération réussie. Le nombre de fichiers et d’avertissements est affiché.

  • Fond rouge : la génération a échoué. Le message d’erreur est affiché directement dans la bannière.

7.2. Fichiers générés

Chaque fichier est présenté dans une carte avec :

  • son nom (en gras, police monospace)

  • son chemin complet

  • sa taille

Deux boutons sont disponibles à droite de chaque carte :

📋

Copie le chemin complet dans le presse-papiers

↗

Ouvre le fichier avec l’application système par défaut (visionneuse JSON, éditeur…)

7.3. Score sbomqs

Si l’option Score qualité sbomqs est cochée et que sbomqs est installé, un bloc indigo s’affiche après la liste des fichiers avec la sortie complète de sbomqs score :

  ── Score sbomqs ──────────────────────────────────
  sbomqs score sbom.cdx.json
  Document Name  Format  Spec   Score   Avg
  sbom.cdx.json  cdx     1.6    8.3/10  8.3

Le texte est sélectionnable pour copier-coller le score.

7.4. Avertissements

Les avertissements sont affichés dans un bloc orange replié. Si leur nombre dépasse 5, un bouton Voir N de plus… permet de les afficher tous. Ces avertissements sont non bloquants : les fichiers SBOM ont bien été générés.

7.5. Erreur fatale

En cas d’échec (code de retour non nul), le message d’erreur apparaît dans un bloc rouge sélectionnable pour faciliter le copier-coller.

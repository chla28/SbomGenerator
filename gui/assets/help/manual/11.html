12.1. Prérequis

Outil Source Rôle

sbomqs

Interlynk

Score global + critères détaillés par catégorie (Identification, Provenance, Integrity…) et profils d’industrie

sbom-scorecard

eBay

Score global en pourcentage, décomposé par catégorie

Les deux outils sont optionnels : si l’un n’est pas installé, sa section affiche un message d’erreur sans bloquer l’autre.

12.1.1. Installer sbom-scorecard (optionnel)

# Via Go
go install github.com/eBay/sbom-scorecard@latest

# Ou télécharger le binaire depuis les releases GitHub
# https://github.com/eBay/sbom-scorecard/releases

# Vérifier
sbom-scorecard --version

Interlynk

Interlynk Scoring Profile

Sans sélection, sbomqs effectue uniquement l’analyse complète (Comprehensive). Avec un ou plusieurs profils cochés, sbomqs reçoit --profile p1,p2,…​ et le détail des critères par profil est affiché dans la carte Profils d’industrie.

Note
 Le choix des profils ne remplace pas l’analyse complète — les deux sections sont toujours affichées simultanément.

12.3. Section sbomqs

Affiche un tableau de critères de qualité par catégorie (Identification, Provenance, Integrity, Completeness, Licensing, Vulnerability, Structural, Component Quality). Une icône ✔ (vert) / ✘ (rouge) indique si le critère est atteint (score = 10/10).

Filtres par catégorie : les FilterChips en haut du tableau permettent d’afficher uniquement les critères d’une ou plusieurs catégories.

Le bouton { } / ≡ bascule entre le tableau et le JSON brut. Le bouton 📋 copie le JSON brut dans le presse-papiers.

12.4. Section Profils d’industrie

Toujours présente après une analyse réussie. Elle affiche pour chaque profil disponible :

  • Un badge coloré avec la note (A / B / C / D / F)

  • Le nom complet du profil

  • Le score sur 10

Si des profils ont été sélectionnés dans la barre de configuration avant l’analyse, chaque profil dispose d’un bouton d’expansion (▶) qui révèle la liste de ses critères avec :

  • Icône ✔/✘, nom du critère, description courte, score

  • Compteur "N / M critères" dans le sous-titre

  • Marqueur pour les critères *obligatoires (required) du profil

Tip
 Quand aucun profil n’est sélectionné, l’en-tête de la section affiche une info-bulle ⓘ rappelant comment activer le détail.

12.5. Section sbom-scorecard

Affiche un graphique à barres pour chaque catégorie de score.

Couleur Signification

Vert

Score ≥ 80 % — excellente qualité

Orange

Score entre 60 % et 80 % — qualité correcte

Rouge

Score < 60 % — qualité insuffisante

Le bouton { } / ≡ bascule entre le graphique et la sortie brute.

12.6. Persistance de l’état

Comme les autres onglets d’analyse, l’onglet Qualité SBOM mémorise son état lors de la navigation entre onglets : le fichier sélectionné et les résultats restent affichés même après avoir consulté un autre onglet.

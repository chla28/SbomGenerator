18. Onglet Comparaison SBOM

L’onglet Comparaison SBOM met en évidence les différences entre deux fichiers SBOM (par exemple avant / après une mise à jour).

  ┌─ SBOM A ─────────────────────────────┐  ┌─ SBOM B ────────────────────────────┐
  │ [ /chemin/vers/avant.cdx.json ] [📂]  │  │ [ /chemin/vers/après.cdx.json ] [📂] │
  └───────────────────────────────────────┘  └──────────────────────────────────────┘
                                                                    [Comparer]

  Ajoutés : 5  │  Supprimés : 3  │  Modifiés : 8  │  Inchangés : 230

  Filtre : [✓ Ajoutés] [✓ Supprimés] [✓ Modifiés] [ Inchangés]
  Recherche : [ openssl…                             ]

  ┌─────────────────────────────────────────────────────────────────────────┐
  │ + │ curl           │ 8.5.0   │ —       │ MIT    │ —                    │
  │ - │ openssl        │ 1.1.1k  │ —       │ OpenSSL│ —                    │
  │ ~ │ bash           │ 5.0 → 5.2│ —      │ GPL-3.0│ —                    │
  └─────────────────────────────────────────────────────────────────────────┘

18.1. Chargement des fichiers

Sélectionnez un fichier dans chaque emplacement (SBOM A et SBOM B) via le bouton 📂 ou en saisissant un chemin. Les formats CycloneDX, SPDX 2.x et SPDX 3.0 JSON-LD sont supportés (mêmes formats que l’onglet Arborescence) ; les deux fichiers comparés n’ont pas besoin d’être dans le même format.

Cliquez sur Comparer pour lancer la comparaison. Le bouton est actif uniquement si les deux fichiers sont sélectionnés.

18.2. Barre de compteurs

Affiche le nombre de composants dans chaque catégorie :

+ (vert)

Ajoutés

Présents dans B, absents de A

− (rouge)

Supprimés

Présents dans A, absents de B

~ (orange)

Modifiés

Présents dans A et B, mais avec version ou licence différente

= (gris)

Inchangés

Identiques dans A et B

18.3. Filtres et recherche

Les puces de filtre permettent d’afficher ou masquer chaque catégorie. Par défaut, les composants Inchangés sont masqués pour se concentrer sur les différences.

Le champ de recherche filtre sur le nom du composant en temps réel, en combinaison avec les filtres de catégorie.

18.4. Colonne de différences

Pour les composants Modifiés :

  • La version affiche l’ancienne valeur barrée et la nouvelle valeur en vert

  • La licence affiche l’ancienne valeur barrée et la nouvelle valeur en vert

18. Onglet Licences SBOM

L’onglet Licences SBOM affiche les licences contenues dans un fichier SBOM existant et permet d’en générer un rapport de conformité (AsciiDoc, Markdown, HTML, CSV ou JSON) en bas de page. Il orchestre la sous-commande sbom-generator licenses en arrière-plan.

  ┌─ [📄 Choisir un fichier…]  [📂 Fichiers générés]   /chemin/vers/sbom.cdx.json ─┐
  └──────────────────────────────────────────────────────────────────────────────┘

  [12 paquet(s)] [5 licence(s)] [2 copyleft fort] [1 sans licence]
  [🔍 Filtrer par licence ou par paquet…]        [Par licence | Tableau]
  ▸ Apache-2.0                                                     3
  ▾ GPL-3.0-or-later  [copyleft fort]                              2
        bash 5.3.9-3.fc44
        …
  ▸ Sans licence détectée  [sans licence]                          1
  ────────────────────────────────────────────────────────────────────
  [Format ▾] [ Fichier de sortie : licences.adoc ] [ Nom (optionnel) ] [⚖ Générer]

  ✔ Rapport généré → licences.adoc

18.1. Licences du SBOM

Dès qu’un fichier est sélectionné, ses licences s’affichent :

  • Une ligne de puces résume le SBOM : nombre de paquets, de licences distinctes, de paquets sous copyleft fort (rouge), copyleft faible (orange) et sans licence détectée (jaune).

  • La vue Par licence liste les licences (avec le nombre de paquets) ; un clic déplie les paquets concernés. La vue Tableau liste un paquet par ligne (paquet, version, licence), triable en cliquant sur un en-tête.

  • Le champ de filtre retient les licences dont l’identifiant contient le texte saisi, ou les paquets dont le nom correspond (insensible à la casse).

Le regroupement et la classification copyleft sont ceux du CLI : ce sont exactement ceux du rapport généré.

18.2. Sélection du fichier source

Deux façons de désigner le fichier :

  • 📄 Choisir un fichier… : ouvre un sélecteur de fichiers du système.

  • 📂 Fichiers générés : menu listant les fichiers SBOM produits pendant la session courante (mêmes formats que l’onglet Arborescence : CycloneDX, SPDX 2.3, SPDX 3.0 JSON-LD).

Le bouton ⚖ Générer n’est actif qu’une fois un fichier sélectionné et un chemin de sortie renseigné.

18.3. Fichier de sortie et nom du document

  • Format : AsciiDoc (défaut), Markdown, HTML (autonome), CSV ou JSON. L’extension du fichier de sortie suit le format tant qu’elle n’a pas été modifiée à la main.

  • Fichier de sortie : chemin du rapport produit (valeur par défaut : licences.adoc).

  • Nom du document (optionnel) : s’il est renseigné, remplace le nom du document dans l’en-tête du rapport ; sinon, le nom du fichier source est conservé.

18.4. Lancement et résultat

Le bouton ⚖ Générer lance sbom-generator licenses sur le fichier sélectionné. Le déroulé de la commande (journal) s’affiche sous les champs, suivi d’une bannière de résultat :

  • ✔ Rapport généré → <fichier> (vert) en cas de succès.

  • ✘ Échec de la génération (code N) (rouge) en cas d’échec — consultez le journal affiché pour le détail de l’erreur.

Le rapport (AsciiDoc ; les autres formats reprennent le même contenu) regroupe les paquets par licence exacte, avec un résumé chiffré en tête (paquets analysés, licences distinctes, paquets sous licence copyleft fort/faible, paquets sans licence détectée), un avertissement listant les identifiants copyleft détectés (GPL/AGPL en fort ; LGPL, MPL, EPL, CDDL, CPL, EUPL en faible), et une section par licence listant les paquets concernés.

18.5. Contraintes

Le format source doit être reconnu (CycloneDX, SPDX 2.3 ou SPDX 3.0). La classification copyleft est une heuristique de repérage par identifiant SPDX, pas une analyse juridique.

8. Onglet Aperçu — Prévisualisation SBOM

L’onglet Aperçu (N) affiche le contenu brut des fichiers SBOM générés directement dans l’interface, sans avoir à ouvrir un éditeur externe.

  ┌─ Fichier : [ sbom.cdx.json ▼ ]                     [📋] ─┐
  │                                                            │
  │  {                                                         │
  │    "bomFormat": "CycloneDX",                               │
  │    "specVersion": "1.6",                                   │
  │    "version": 1,                                           │
  │    "metadata": {                                           │
  │      "component": {                                        │
  │        "name": "Mon Application 2.1.0",                   │
  │        ...                                                 │
  └────────────────────────────────────────────────────────────┘

8.1. Sélection du fichier

Un menu déroulant en haut de l’onglet liste tous les fichiers non-PDF générés dans la session courante. Le premier fichier est sélectionné automatiquement à la fin de la génération.

8.2. Comportement du rendu

  • Le contenu est affiché en police monospace sur fond sombre, comme le terminal.

  • Les fichiers JSON (CycloneDX, SPDX) sont affichés tels quels.

  • Les fichiers Markdown et AsciiDoc sont également affichés en texte brut.

  • Au-delà de 50 000 caractères, le contenu est tronqué avec une note indiquant la taille totale réelle.

  • Le texte est sélectionnable.

8.3. Copier le contenu

Le bouton 📋 en haut à droite copie l’intégralité du contenu affiché dans le presse-papiers.

Note
 L’onglet Aperçu ne remplace pas un outil dédié pour explorer de gros fichiers JSON. Pour les fichiers très volumineux, utilisez le bouton ↗ (onglet Résultats) pour ouvrir le fichier dans votre application système.

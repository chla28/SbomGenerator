9. Onglet OSV-Scanner — Analyse de vulnérabilités

L’onglet OSV-Scanner utilise l’outil de Google pour rechercher les vulnérabilités à partir d’un fichier SBOM ou d’une image de conteneur. Son interface est identique à celle de l’onglet Grype.

  ┌───────────────────────────────────────────────────────────────────┐
  │  [ Fichier SBOM ] [ Image de conteneur ]                          │
  │  Fichier SBOM : [ /projet/sbom.cdx.json         ] [Choisir ▾]   │
  │  Config toml  : [                               ] [Choisir ▾]   │
  │                                                      [Analyser]  │
  ├───────────────────────────────────────────────────────────────────┤
  │  ⚠ 3 vulnérabilité(s) : 1 Critical, 2 High                       │
  ├───────────────────────┬───────────────────────────────────────────┤
  │ [Vulnérabilités (3)]  │ [JSON brut]                               │
  └───────────────────────┴───────────────────────────────────────────┘

9.1. Indicateur de version

Même comportement que dans l’onglet Grype (voir Indicateur de version), appliqué à osv-scanner. Le badge est affiché en haut du panneau de configuration dès que la vérification de démarrage est terminée.

9.2. Prérequis

osv-scanner doit être installé et accessible dans le PATH (voir Installer osv-scanner (optionnel)).

9.3. Sélection de la source à analyser

Même bascule Fichier SBOM / Image de conteneur que dans l’onglet Grype (voir Sélection de la source à analyser). En mode Fichier SBOM, le champ est pré-rempli avec le dernier fichier généré ; le bouton Choisir propose :

  • Type filtré : fichiers .json et .jsonld

  • Tous les fichiers

En mode Image de conteneur, le champ accepte une référence de registre (ex. nginx:latest) ou une archive locale (docker save, via le bouton dédié) — au format .tar, .tar.gz ou .tgz.

Note
 Contrairement à Grype et Trivy, OSV-Scanner ne sait pas lire un répertoire au format OCI layout directement : seule l’archive est proposée ici. Il n’a pas non plus d’option de plateforme (--platform).

L’option Par couche est disponible en mode image, comme pour Grype — voir Analyse par couche (source « Image de conteneur »).

9.4. Configuration optionnelle (toml)

Chemin vers un fichier de configuration osv-scanner.toml permettant de définir des règles d’ignorance par ID de vulnérabilité. Ce paramètre est optionnel.

9.5. Lancer l’analyse

Cliquez sur Analyser. En mode Fichier SBOM, OSV-Scanner s’exécute avec :

osv-scanner --format json --sbom /chemin/vers/sbom.cdx.json

En mode Image de conteneur, la sous-commande change (--sbom ne sait pas scanner une image) :

osv-scanner scan image --format json nginx:latest
# ou, pour une archive locale :
osv-scanner scan image --format json --archive /chemin/vers/image.tar

Un code de retour 1 indique qu’au moins une vulnérabilité a été trouvée (c’est normal, pas une erreur) ; un code supérieur à 1 indique une erreur.

9.6. Résultats

9.6.1. Vue Vulnérabilités

Même interface que l’onglet Grype : barre de recherche + tri + export CSV, filtres par sévérité, puis liste des vulnérabilités.

  [ Rechercher...                        ] [⬇]
  Filtre : [Critical (1)] [High (2)] [Medium (0)] [Low (0)]  [Tout voir]

  ┌────────────┬────────────────────┬────────────────┬────────────────────────┐
  │ SÉVÉRITÉ ↕ │ CVE/ID ↕           │ PAQUET ↕       │ VERSION CORRIGÉE ↕     │
  ├────────────┼────────────────────┼────────────────┼────────────────────────┤
  │ CRITICAL   │ CVE-2023-12345     │ requests 2.28  │ 2.31.0                 │
  └────────────┴────────────────────┴────────────────┴────────────────────────┘

Recherche et tri : identiques à l’onglet Grype (voir [sec-vue-table]).

Fusion des doublons visuels : même comportement (badge ×N) que l’onglet Grype — voir [sec-vue-table].

Export CSV : le bouton ⬇ exporte la vue filtrée (déjà fusionnée). Colonnes : Sévérité, CVE/ID, Paquet, Version installée, Version corrigée, Écosystème, Emplacements.

Export AsciiDoc + PDF : le bouton ⬥ exporte la même vue filtrée dans un rapport AsciiDoc (résumé par sévérité + tableau détaillé), avec conversion PDF automatique si asciidoctor-pdf est installé — voir la description complète dans l’onglet Grype ([sec-vue-table]).

Filtre par date : même barre que l’onglet Grype (voir [sec-vue-table]). Le champ Publication correspond à published du JSON OSV, le champ Modification à modified. L’option Propager copie le filtre vers les onglets Grype et Trivy.

Colonnes :

  • Badge de sévérité coloré

  • Identifiant CVE (cliquable — copie dans le presse-papiers)

  • Nom et version du paquet affecté

  • Version corrigée (si disponible)

La sévérité est déterminée depuis le champ database_specific.severity ou depuis les scores CVSS présents dans le JSON OSV.

9.6.2. Vue JSON brut

Affiche le JSON complet retourné par osv-scanner, utile pour inspecter les métadonnées détaillées de chaque vulnérabilité.

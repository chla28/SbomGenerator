9. Onglet Tâches — File d’attente d’analyses

L’onglet Tâches met en file des analyses de vulnérabilités : elles s’exécutent une à une (les scanners sont gourmands et partagent leur base de vulnérabilités) et leurs résultats alimentent le Tableau de bord (cartes, comparaison, remédiation, tendance, rapport).

  1. Choisissez le SBOM à analyser : le premier SBOM JSON généré est proposé automatiquement, Parcourir… en choisit un autre.

  2. Cochez les scanners (Grype, OSV-Scanner, Trivy).

  3. Ajouter à la file : une analyse par scanner coché apparaît.

Chaque ligne indique son état — En attente, En cours… (avec la durée), Terminée (nombre de vulnérabilités), Échec (message d’erreur : outil introuvable, sortie illisible…) ou Annulée — et propose :

  • Annuler (⏹) : retire une analyse en attente, ou arrête le processus d’une analyse en cours ;

  • Relancer (↺) : remet en file une analyse en échec ou annulée ;

  • Retirer (✕) : supprime la ligne.

Tout annuler interrompt toutes les analyses en attente ou en cours ; Retirer les terminées nettoie la liste. Les enrichissements CISA KEV / EPSS / PoC suivent le réglage « enrichir en ligne » des onglets de scan.

Note
 Les résultats d’une analyse en file remplacent ceux du même scanner dans le tableau de bord ; les tableaux des onglets Grype / OSV-Scanner / Trivy ne les affichent pas (ils gardent leurs propres analyses).

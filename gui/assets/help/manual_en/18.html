19. SBOM Merge tab

The SBOM Merge tab combines several SBOM files into a single document, deduplicating the common components. It orchestrates the sbom-generator merge subcommand in the background.

  ┌─ [➕ Add files…]  [📂 Generated files]   3 file(s) selected ─┐
  │  📄 base.cdx.json         /path/to/base.cdx.json                          [✕]  │
  │  📄 extra-1.cdx.json      /path/to/extra-1.cdx.json                       [✕]  │
  │  📄 extra-2.cdx.json      /path/to/extra-2.cdx.json                       [✕]  │
  └──────────────────────────────────────────────────────────────────────────────┘

  [ Output file: merged.cdx.json ]  [ Document name (optional) ]  [🔀 Merge]

  ✔ Merge succeeded → merged.cdx.json

19.1. Selecting the files to merge

Two ways to fill the list:

  • ➕ Add files…: opens a two-entry menu — .json / .jsonld (filters the picker on these extensions) or All files (no filter, for SBOMs whose extension is not .json, e.g. .cdx, .spdx, bom, or with no extension). Multiple selection is possible in both cases. The content must remain CycloneDX or SPDX 2.x JSON whatever the file name.

  • 📂 Generated files: menu listing the SBOM files produced during the current session (same formats as the Tree tab, except SPDX 3.0 — see Constraints below).

Each file in the list can be removed individually through the ✕ button. The 🔀 Merge button is only active with at least two selected files and a filled output path.

19.2. Output file and document name

  • Output file: path of the produced merged document (default value: merged.cdx.json).

  • Document name (optional): if filled in, replaces the document name in the merged file; otherwise, the name of the first source file is kept.

19.3. Launch and result

The 🔀 Merge button launches sbom-generator merge with the selected files. The command output (log) is displayed under the fields, followed by a result banner:

  • ✔ Merge succeeded → <file> (green) on success.

  • ✘ Merge failed (code N) (red) on failure — check the displayed log for the error detail.

19.4. Constraints

All the selected files must be in the same format (that of the first file in the list): CycloneDX or SPDX 2.3. The output format follows that of the first file. The SPDX 3.0 (JSON-LD) format is not supported as merge input.

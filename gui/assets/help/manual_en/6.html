7. Preview tab — SBOM preview

The Preview (N) tab shows the raw content of the generated SBOM files directly in the interface, without having to open an external editor.

  ┌─ File: [ sbom.cdx.json ▼ ]                         [📋] ─┐
  │                                                            │
  │  {                                                         │
  │    "bomFormat": "CycloneDX",                               │
  │    "specVersion": "1.6",                                   │
  │    "version": 1,                                           │
  │    "metadata": {                                           │
  │      "component": {                                        │
  │        "name": "My Application 2.1.0",                    │
  │        ...                                                 │
  └────────────────────────────────────────────────────────────┘

7.1. File selection

A drop-down menu at the top of the tab lists all the non-PDF files generated in the current session. The first file is selected automatically at the end of the generation.

7.2. Rendering behavior

  • The content is displayed in a monospace font on a dark background, like the terminal.

  • JSON files (CycloneDX, SPDX) are displayed as is.

  • Markdown and AsciiDoc files are also displayed as plain text.

  • Beyond 50,000 characters, the content is truncated with a note indicating the real total size.

  • The text is selectable.

7.3. Copying the content

The 📋 button at the top right copies the whole displayed content to the clipboard.

Note
 The Preview tab does not replace a dedicated tool for exploring large JSON files. For very large files, use the ↗ button (Results tab) to open the file in your system application.

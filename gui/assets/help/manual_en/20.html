21. Keyboard shortcuts

The ⌨ button in the title bar (or Ctrl+/) shows this list.

Shortcut Action

Ctrl+Enter

Start the generation (same validation as the button)

Esc

Stop the running task

Ctrl+1 … Ctrl+9

Go to tab 1 to 9

Ctrl+Page Down / Ctrl+Page Up

Next / previous tab (wraps around)

F1

Open this manual

Ctrl+/

Show the shortcut list

F3 / Shift+F3

In the manual: next / previous search match

In tables, Tab and the arrow keys move between rows; Enter or Space opens a row’s detail. In dark theme, light-background areas (banners, "seen by a single scanner" rows, comparison rows) keep a readable dark text.

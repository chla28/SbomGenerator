The Results (N) tab shows the number of generated files in its label.

  ├─────────────────────────────────────────────────────┤
  │ 📄 sbom.spdx.json                                   │

  ⚠ Warnings (1)
  Warning: unknown license for 'mylib-1.2.3'

6.1. Result banner

  • Green background: the generation succeeded. The number of files and warnings is displayed.

  • Red background: the generation failed. The error message is displayed directly in the banner.

6.2. Generated files

Each file is presented in a card with:

  • its name (bold, monospace font)

  • its full path

  • its size

Two buttons are available on the right of each card:

📋

Copies the full path to the clipboard

↗

Opens the file with the default system application (JSON viewer, editor…)

6.3. sbomqs score

If the sbomqs quality score option is checked and sbomqs is installed, an indigo block is displayed after the file list with the complete output of sbomqs score:

  ── sbomqs score ──────────────────────────────────
  sbomqs score sbom.cdx.json
  Document Name  Format  Spec   Score   Avg
  sbom.cdx.json  cdx     1.6    8.3/10  8.3

The text is selectable to copy-paste the score.

6.4. Warnings

Warnings are displayed in a collapsed orange block. If there are more than 5, a Show N more… button displays them all. These warnings are non-blocking: the SBOM files were generated.

6.5. Fatal error

On failure (non-zero exit code), the error message appears in a selectable red block to make copy-pasting easier.

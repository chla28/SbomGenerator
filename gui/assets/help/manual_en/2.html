3. Requirements & installation

3.1. Requirements

Component Mandatory Role

sbom-generator

Yes

SBOM file generation

syft

No

OCI image analysis (Configuration panel — default OCI tool)

skopeo / trivy / cdxgen

No

OCI image analysis — alternative backends (Configuration panel — OCI tool); cdxgen requires Node.js

trivy (CVE analysis)

No

CVE vulnerability analysis (Trivy tab)

grype

No

CVE vulnerability analysis (Grype tab)

osv-scanner

No

CVE vulnerability analysis (OSV-Scanner tab)

trivy

No

CVE vulnerability analysis (Trivy tab)

asciidoctor-pdf

No

Automatic PDF conversion of the AsciiDoc report (SBOM, or vulnerability export from Grype/OSV-Scanner/Trivy)

sbomqs

No

SBOM quality score (option in Configuration)

3.1.1. Checking that the tools are available

sbom-generator --version
syft version
grype version
osv-scanner --version
trivy --version
cdxgen --version
asciidoctor-pdf --version
sbomqs version

3.1.2. Installing syft (optional)

# Official Anchore script
curl -sSfL https://raw.githubusercontent.com/anchore/syft/main/install.sh \
  | sh -s -- -b /usr/local/bin

# Check
syft version

3.1.3. Installing cdxgen (optional)

# Via npm (requires Node.js ≥ 20)
npm install -g @cyclonedx/cdxgen

# Check
cdxgen --version

3.1.4. Installing grype

# Official Anchore script
curl -sSfL https://raw.githubusercontent.com/anchore/grype/main/install.sh \
  | sh -s -- -b /usr/local/bin

# Check
grype version

3.1.5. Installing osv-scanner (optional)

# Official Google script
curl -sSfL \
  https://raw.githubusercontent.com/google/osv-scanner/main/scripts/install.sh \
  | sh -s -- -b /usr/local/bin

# Or via Go (if Go is installed)
go install github.com/google/osv-scanner/cmd/osv-scanner@latest

# Check
osv-scanner --version
Note
 osv-scanner must be reachable in the PATH when the GUI is launched. If the tool is installed through Go in ~/go/bin, add that folder to the PATH of your graphical session (~/.profile or ~/.bash_profile).

3.1.6. Installing trivy (optional)

# Official Aqua Security script
curl -sfL https://raw.githubusercontent.com/aquasecurity/trivy/main/contrib/install.sh \
  | sh -s -- -b /usr/local/bin

# Or via the package manager (Fedora/RHEL)
sudo rpm -ivh https://github.com/aquasecurity/trivy/releases/latest/download/trivy_Linux-64bit.rpm

# Check
trivy --version

3.1.7. Installing asciidoctor-pdf (optional)

gem install asciidoctor-pdf

3.1.8. Installing sbomqs (optional)

# Download the latest release from GitHub
# https://github.com/interlynk-io/sbomqs/releases
curl -sSfL https://raw.githubusercontent.com/interlynk-io/sbomqs/main/install.sh \
  | sh -s -- -b /usr/local/bin

# Check
sbomqs version

3.2. Starting the interface

sbom_generator_gui

If the binary is not in the PATH, run it directly:

/path/to/sbom_generator_gui

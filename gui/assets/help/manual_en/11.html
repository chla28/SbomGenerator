12.1. Requirements

Tool Source Role

sbomqs

Interlynk

Global score + detailed criteria per category (Identification, Provenance, Integrity…) and industry profiles

sbom-scorecard

eBay

Global score as a percentage, broken down by category

Both tools are optional: if one is not installed, its section displays an error message without blocking the other.

12.1.1. Installing sbom-scorecard (optional)

# Via Go
go install github.com/eBay/sbom-scorecard@latest

# Or download the binary from the GitHub releases
# https://github.com/eBay/sbom-scorecard/releases

# Check
sbom-scorecard --version

With no selection, sbomqs only performs the full analysis (Comprehensive). With one or more profiles checked, sbomqs receives --profile p1,p2,…​ and the criteria detail per profile is displayed in the Industry profiles card.

Note
 Choosing profiles does not replace the full analysis — both sections are always displayed simultaneously.

12.3. sbomqs section

Displays a table of quality criteria per category (Identification, Provenance, Integrity, Completeness, Licensing, Vulnerability, Structural, Component Quality). A ✔ (green) / ✘ (red) icon indicates whether the criterion is met (score = 10/10).

Category filters: the FilterChips at the top of the table let you display only the criteria of one or more categories.

The { } / ≡ button toggles between the table and the raw JSON. The 📋 button copies the raw JSON to the clipboard.

12.4. Industry profiles section

Always present after a successful analysis. It displays for each available profile:

  • A colored badge with the grade (A / B / C / D / F)

  • The full name of the profile

  • The score out of 10

If profiles were selected in the configuration bar before the analysis, each profile has an expand button (▶) that reveals the list of its criteria with:

  • ✔/✘ icon, criterion name, short description, score

  • “N / M criteria” counter in the subtitle

  • marker for the *mandatory (required) criteria of the profile

Tip
 When no profile is selected, the section header displays an ⓘ tooltip recalling how to enable the detail.

12.5. sbom-scorecard section

Displays a bar chart for each score category.

Color Meaning

Green

Score ≥ 80 % — excellent quality

Orange

Score between 60 % and 80 % — acceptable quality

Red

Score < 60 % — insufficient quality

The { } / ≡ button toggles between the chart and the raw output.

12.6. State persistence

Like the other analysis tabs, the SBOM Quality tab remembers its state when navigating between tabs: the selected file and the results remain displayed even after viewing another tab.

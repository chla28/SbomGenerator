20. SBOM Licenses tab

The SBOM Licenses tab displays the licenses contained in an existing SBOM file and lets you generate a compliance report (AsciiDoc, Markdown, HTML, CSV or JSON) at the bottom of the page. It orchestrates the sbom-generator licenses subcommand in the background.

  ┌─ [📄 Choose a file…]  [📂 Generated files]   /path/to/sbom.cdx.json ─┐
  └──────────────────────────────────────────────────────────────────────────────┘

  [12 package(s)] [5 license(s)] [2 strong copyleft] [1 unlicensed]
  [🔍 Filter by license or package…]             [By license | Table]
  ▸ Apache-2.0                                                     3
  ▾ GPL-3.0-or-later  [strong copyleft]                            2
        bash 5.3.9-3.fc44
        …
  ▸ No license detected  [unlicensed]                              1
  ────────────────────────────────────────────────────────────────────
  [Format ▾] [ Output file: licenses.adoc ] [ Name (optional) ] [⚖ Generate]

  ✔ Report generated → licenses.adoc

20.1. SBOM licenses

As soon as a file is selected, its licenses are displayed:

  • A row of chips summarizes the SBOM: number of packages, distinct licenses, packages under strong copyleft (red), weak copyleft (orange) and with no detected license (yellow).

  • The By license view lists the licenses (with the number of packages); a click expands the matching packages. The Table view lists one package per row (package, version, license), sortable by clicking a header.

  • The filter field keeps the licenses whose identifier contains the entered text, or the packages whose name matches (case-insensitive).

The grouping and the copyleft classification are those of the CLI: they are exactly those of the generated report.

20.2. Selecting the source file

Two ways to designate the file:

  • 📄 Choose a file…: opens a system file picker.

  • 📂 Generated files: menu listing the SBOM files produced during the current session (same formats as the Tree tab: CycloneDX, SPDX 2.3, SPDX 3.0 JSON-LD).

The ⚖ Generate button is only active once a file is selected and an output path is filled in.

20.3. Output file and document name

  • Format: AsciiDoc (default), Markdown, HTML (standalone), CSV or JSON. The extension of the output file follows the format as long as it has not been modified by hand.

  • Output file: path of the produced report (default value: licenses.adoc).

  • Document name (optional): if filled in, replaces the document name in the report header; otherwise, the name of the source file is kept.

20.4. Launch and result

The ⚖ Generate button launches sbom-generator licenses on the selected file. The command output (log) is displayed under the fields, followed by a result banner:

  • ✔ Report generated → <file> (green) on success.

  • ✘ Generation failed (code N) (red) on failure — check the displayed log for the error detail.

The report (AsciiDoc; the other formats reproduce the same content) groups the packages by exact license, with a figures summary at the top (analyzed packages, distinct licenses, packages under strong/weak copyleft license, packages with no detected license), a warning listing the detected copyleft identifiers (GPL/AGPL as strong; LGPL, MPL, EPL, CDDL, CPL, EUPL as weak), and one section per license listing the matching packages.

20.5. Constraints

The source format must be recognized (CycloneDX, SPDX 2.3 or SPDX 3.0). The copyleft classification is a detection heuristic based on the SPDX identifier, not a legal analysis.

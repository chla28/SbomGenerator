16. SBOM Comparison tab

The SBOM Comparison tab highlights the differences between two SBOM files (for example before / after an update).

  ┌─ SBOM A ─────────────────────────────┐  ┌─ SBOM B ────────────────────────────┐
  │ [ /path/to/before.cdx.json ] [📂]     │  │ [ /path/to/after.cdx.json ] [📂]     │
  └───────────────────────────────────────┘  └──────────────────────────────────────┘
                                                                    [Compare]

  Added: 5  │  Removed: 3  │  Modified: 8  │  Unchanged: 230

  Filter : [✓ Added] [✓ Removed] [✓ Modified] [ Unchanged]
  Search : [ openssl…                                ]

  ┌─────────────────────────────────────────────────────────────────────────┐
  │ + │ curl           │ 8.5.0   │ —       │ MIT    │ —                    │
  │ - │ openssl        │ 1.1.1k  │ —       │ OpenSSL│ —                    │
  │ ~ │ bash           │ 5.0 → 5.2│ —      │ GPL-3.0│ —                    │
  └─────────────────────────────────────────────────────────────────────────┘

16.1. Loading the files

Select a file in each slot (SBOM A and SBOM B) through the 📂 button or by typing a path. The CycloneDX, SPDX 2.x and SPDX 3.0 JSON-LD formats are supported (same formats as the Tree tab); the two compared files do not need to be in the same format.

Click Compare to start the comparison. The button is only active if both files are selected.

16.2. Counter bar

Displays the number of components in each category:

+ (green)

Added

Present in B, absent from A

− (red)

Removed

Present in A, absent from B

~ (orange)

Modified

Present in A and B, but with a different version or license

= (grey)

Unchanged

Identical in A and B

16.3. Filters and search

The filter chips let you show or hide each category. By default, Unchanged components are hidden to focus on the differences.

The search field filters on the component name in real time, in combination with the category filters.

16.4. Differences column

For Modified components:

  • The version shows the old value struck through and the new value in green

  • The license shows the old value struck through and the new value in green

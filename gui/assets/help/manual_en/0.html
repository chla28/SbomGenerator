1. Quick start

This chapter is the first-use walkthrough: in five minutes, from opening the application to a vulnerability dashboard. Each screen is detailed in the following chapters.

  1. Check the requirements. The application drives external tools: the sbom-generator CLI (shipped with the application), then, depending on what you want to do, syft/skopeo (container images), grype, osv-scanner, trivy (vulnerability analysis), sbomqs (quality), asciidoctor-pdf (PDF reports). The tabs concerned clearly name a missing tool. See Requirements & installation.

  2. Generate a first SBOM. In the left panel, Input section, choose (or drag and drop) a package list file, a lockfile (package-lock.json, pubspec.lock…) or a folder; in Output, give a base name and tick at least one format (CycloneDX to start with). Click ▶ Generate SBOM (or press Ctrl+Enter). The Progress tab shows the progress; the Results tab lists the files produced.

  3. Scan for vulnerabilities. Open the Grype, OSV-Scanner or Trivy tab: the SBOM you just generated is already selected. Click Scan. To run the three scanners at once, use the Tasks tab: queue the scans, they run one at a time and can be cancelled or retried.

  4. Read the dashboard. The Dashboard tab gathers the results: one card per scanner, cross-scanner comparison, remediation (which update removes the most risk), and — if you already scanned the target — the trend since an earlier session.

  5. Decide. In a CVE’s detail, Declare via VEX… marks a CVE as not affected (with a justification): it disappears from the dashboard and can be exported as OpenVEX or CycloneDX VEX.

  6. Share. Save session… keeps the results in a file; AsciiDoc + PDF export produces a report.

Tip
 Everything is also available from the keyboard: Ctrl+Enter starts the generation, Esc stops it, Ctrl+1…9 switches tab, F1 opens this manual and Ctrl+/ lists the shortcuts (see Keyboard shortcuts). In the manual, the search field highlights the matches inside the chapter; F3 / Shift+F3 jump to the next / previous match.

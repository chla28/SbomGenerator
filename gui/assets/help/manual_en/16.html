17. SBOM Viewer tab

The SBOM Viewer tab lets you open and explore any CycloneDX or SPDX SBOM file from the file system, independently of a generation in progress.

17.1. Opening a file

Click 📂 Open an SBOM file… to browse the file system. The picker offers the .json, .jsonld, .cdx.json, .spdx.json extensions.

Supported formats:

  • CycloneDX 1.6 — components[] with the fields name, version, type, purl, licenses, description

  • SPDX 2.x — packages[] with the fields name, versionInfo, licenseConcluded, summary, externalRefs[purl]

  • SPDX 3.0 JSON-LD — software:Package elements of the @graph, with the fields name, software:packageVersion, concludedLicense/declaredLicense, summary, externalIdentifier[purl]

The information bar displays the detected format, the document name and the total number of loaded components.

17.2. Per-layer navigation

For an SBOM produced with --per-layer, the layer banner described in Per-layer navigation (--per-layer) is displayed under the header: it lets you switch from the global SBOM to each layer SBOM without going back to the file picker.

17.3. Filter and search

The search field filters the components in real time on:

  • the package name

  • the version

  • the license

  • the PURL

  • the layer (SBOM produced with --per-layer)

The All types drop-down menu filters by ecosystem type (rpm, java, pypi, npm, deb, apk…). The two filters combine.

17.4. Components table

The table displays the columns Name, Version, Type, License and PURL, plus, for an SBOM produced with --per-layer, a Layer column (global SBOM: originating layer and layers that modified the component) or Change (layer SBOM: added, modified (was <version>)). Click a column header to sort in ascending order, click again to reverse the order.

17.5. Details panel

Click a table row to display a details panel on the right, summarizing all the fields of the selected component: name, version, type, license, description and PURL.

17.6. Persistence

The opened file and the active filters are remembered when navigating between tabs. The file is not reloaded automatically if its content changes on disk.

Note
 The SBOM Viewer is a standalone tab — it can be used with any SBOM file, not only those generated by sbom_generator.

5.1. Terminal color codes

Color Meaning

Cyan

Shell command launched (first line, prefixed with $)

White (default)

General information

Blue

Start of a step (Generating, Resolving, Found, Analysed)

Orange

Warning (Warning:, ⚠)

Red

Fatal error (Error:)

Green

Produced file (SBOM written, PDF written)

Light blue

PDF conversion in progress

The terminal text is selectable to copy-paste error messages.

5.2. Progress bar

The progress bar shows the number of processed packages, the percentage and the name of the current package. It only appears during the generation.

Once the generation is finished, the Results tab is activated automatically on success.

5.3. Log export

Once the generation is finished, two buttons appear at the top of the terminal:

Copy

Copies all the logs to the clipboard

Save

Opens a save dialog to write the logs to a .log file

5.4. Post-generation summary

At the end of a successful generation, a summary card is displayed at the bottom of the tab:

  • number of analyzed packages

  • number of generated SBOM files

  • number of warnings (in orange if > 0)

The card outline is green on success with no warning, orange otherwise.

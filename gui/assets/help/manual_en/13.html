14. SBOM Tree tab

The SBOM Tree tab lets you explore the components of an SBOM file (CycloneDX or SPDX) without opening a JSON editor.

  ┌─ File: [ sbom.cdx.json ▼ ]  [📂 Open…]                            ─┐
  │  CycloneDX 1.6  •  My Application 2.1.0  •  246 components          │
  ├─ Group by: [None] [Type] [License]                                    │
  ├────────────────────────────────────────────────────────────────────────┤
  │ ▶ rpm  (132)                                                           │
  │ ▼ python  (89)                                                         │
  │    requests  2.31.0  MIT  pkg:pypi/requests@2.31.0                    │
  │    urllib3   1.26.14 MIT  pkg:pypi/urllib3@1.26.14                    │
  │    ...                                                                 │
  │ ▶ deb  (25)                                                            │
  └────────────────────────────────────────────────────────────────────────┘

14.1. Selecting the SBOM file

The drop-down menu lists the SBOM files generated in the current session. The first .cdx.json, .spdx.json or .spdx3.jsonld file is selected automatically. Layer SBOMs (--per-layer) are not listed there: they are opened from the layer selector (see Per-layer navigation (--per-layer)).

The Open… button lets you load any file from the file system.

Supported formats:

  • CycloneDX 1.6 — .cdx.json (components[] field)

  • SPDX 2.x — .spdx.json (packages[] field)

  • SPDX 3.0 JSON-LD — .spdx3.jsonld

14.2. Information bar

After loading, a metadata line is displayed:

  • SBOM format and version

  • Document name / main component

  • Total number of components

14.3. Grouping

The Group by selector offers three modes:

None

All components in a flat list sorted by name

Type

Grouping by package type (rpm, python, deb…)

License

Grouping by SPDX license expression

Layer

SBOM produced with --per-layer only: grouping by originating layer (Layer 01, Layer 02… in the global SBOM) or by change (Added / Modified in a layer SBOM)

The icons to the right of the selector expand or collapse all the groups.

Groups are collapsible. Click a group header to open or close it.

14.4. Component details

Click a component to display its details (expandable field):

  • PURL (Package URL) — clickable to copy to the clipboard

  • Version

  • Type

  • License

  • Layer — originating layer (global SBOM) or change (layer SBOM), for an SBOM produced with --per-layer

Note
 Components with no PURL in the SBOM do not display this field.

14.5. Per-layer navigation (--per-layer)

When the opened file belongs to a set produced with --per-layer (global SBOM or layer SBOM), an N layer(s) banner is displayed under the file bar, in this tab as in the SBOM Viewer:

  • a Global SBOM / Layer 1/N (digest) … drop-down menu directly opens the chosen SBOM; for each layer, it recalls the counters (+added ~modified -removed) and the build instruction;

  • under the menu, the description of the displayed document: digest, instruction, counters of the layer (or number of layers and mode for the global one);

  • an N removed badge lists on hover the components removed by the layer (rootfs mode).

The files of the same set are found by their name in the directory of the opened file (<base>.<ext> and <base>.layer-NN-<digest>.<ext>, same format): navigation also works for a set opened through Open….

14.6. State persistence

The tab remembers its state (selected file, grouping, open/closed groups) when navigating between tabs.
